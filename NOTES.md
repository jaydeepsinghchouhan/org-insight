# 📝 Project Notes

## 🤖 AI Tools Used & How They Helped

- **Claude.ai**  
  - Helped generate code templates, create theme configurations, and update mock data.  
  - **Benefit:** Saved time by automating repetitive coding tasks and providing quick, structured solutions.

- **GitHub Copilot**  
  - Assisted with writing and refactoring React components, integrating theming, and managing state logic.  
  - **Benefit:** Reduced development time by completing boilerplate code and suggesting best practices.

💡 *Both tools significantly reduced manual repetitive work, allowing more focus on high-level architecture and UI/UX design.*
